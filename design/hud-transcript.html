What stays the same in all three: the final transcript, the paste, and the note are untouched — the live text never reaches the target application, it only appears here. Recording still starts and stops on the same hotkey, and Esc still throws the take away.
CadenceA snapshot of the audio so far, transcribed every ~1.2 s. Measured: 0.59 s for the first 8 seconds, and the engine is already warm, so this is free at the start of a take. It gets more expensive as a take grows — at two minutes the same work costs ~2.5 s — so the interval should stretch with the length, and past a minute the transcript is a courtesy rather than a read-out.
The header problemA WAV being written has zero in its size fields, and the engine refuses it: Invalid audio data… must be at least 300ms. Snapshot it, patch the two size fields, and it transcribes correctly — verified against a take that was still recording.
